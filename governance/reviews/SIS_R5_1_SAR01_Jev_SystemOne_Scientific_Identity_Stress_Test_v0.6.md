# SAR-01 v0.6 — Jev / System One Models as a Stress Test of System Intelligence

> **SCIENTIFIC REVIEW ONLY — SAR-01 OPEN / NOT FROZEN.** This note does not adopt or amend the R5.1 Master. It records the science-owner's current preference for **B: System Intelligence as a higher-level, multidimensional scientific construct**, not a new core primitive or a universal score.

## 1. External fact and scientific status

**Jev** was publicly launched by TypeSafe AI on 2026-09-15, described as a non-generative System One model: input state plus typed questions, output bounded Choice/Score/Noul judgments and probabilities. The model's underlying architecture/weights are not public. The **System One** label is a product/model-interface designation, *not* SIS ontology and *not* proof of human-like dual-process cognition.

Sources:
- TypeSafe, launch: https://typesafe.ai/blog/introducing-system-one-models-and-jev
- Jev 1.14 (2026-10-14): https://typesafe.ai/blog/jev-1-14
- Vercel integration/authority separation: https://vercel.com/i/jev-agent-control

Independent evidence to separate from vendor claims:
- Deußer et al., 2026-09-29, benchmark Jev 1.13 on 37 datasets, 346,009 requests; results are task-dependent: https://arxiv.org/abs/2609.37647
- Meng, 2026, evaluation of calibration dependence on wording and task: https://escholarship.org/uc/item/4t4449jv
- Imperatrice et al., 2026-10-14, bias/order sensitivity, 41,500 judgments: https://arxiv.org/abs/2610.19619
- Yang et al., 2026-10-18, limits of one-pass decisions for multi-step changes and stale state: https://arxiv.org/abs/2610.24929
- Geuter et al., 2026-10-12, open language models with a decision head can serve Jev-like functions: https://arxiv.org/abs/2610.17205
- Madrid-García & Merino-Barbancho, 2026-09-27, medical preprint shows task-dependent clinical limits: https://arxiv.org/abs/2609.34024

**Caution:** Typed output protects schema/option shape, NOT semantic correctness, calibrated confidence in every setting, authority, or clinical safety. Jev 1.14 differs from the version studied in most independent 1.13 reports.

## 2. Scientific impact — three theses

**Thesis A (no Core rewrite needed):** The current R5.1 `Components + Relations + State + Observation + Control + Dynamics`, `π:H_t→A_t`, SCF/SDR/ASR, CSCI and capability frontiers can already express a typed-decision model as a capability-bearing component. Jev does not compel a new core primitive or fourth scientific program.

**Thesis B (scientific-identity tension):** A Jev-like specialized learned selector can perform decisions otherwise delegated to a generative LLM. Therefore `LLM = necessary unique brain` is empirically contestable. Maintain **LLM-centric as a focal empirical program** if desired, but avoid making LLM presence an axiom defining all possible system-intelligence phenomena. A Jev-only + SOP system can be a legitimate negative control / boundary case without turning conventional ML architectures into the SIS research topic.

**Thesis C (role vs implementation):** Separate (i) generative interpretation/planning, (ii) learned probabilistic selection/routing, (iii) predefined policy/permissions, (iv) physical/digital tool execution, (v) external knowledge and state, (vi) scientific measurement/reference. The Jev role may be ASR when it makes history-conditioned selections; a static comparison of adding it may instead be SCF. A runtime Jev judge cannot automatically serve as independent scientific reference.

## 3. Open proposed extension — role annotation, not new ontology

`CognitiveRoleAnnotation` *optional, not normative*:
- focal_model (generative planner or decision selector), component IDs, task and decision scope
- learned_decision_role vs fixed_rule_role
- state provenance and freshness, input information boundary and authorized actions
- probability calibration / selective-risk policy (model/version, domain, threshold, coverage, abstain/escalate)
- reference/evaluator independence and evidence linkage

Do NOT equate product labels "System One/System Two" with primitives, or interpret Jev branding as scientific evidence.

## 4. Discriminating empirical stress test

Use a pre-registered matched-task factorial:
1. Fixed-rule controller + same B3 procedural body + same manual
2. Jev/decision model + B3 + manual, with no generative LLM
3. Weak generative LLM + B3 + manual
4. Weak LLM + Jev decision module + B3 + manual
5. Strong LLM + minimal body/manual (compensation reference)
6. Strong LLM + Jev + B3, where scientifically needed

Separate the *system contribution* of adding Jev, the **incremental LLM contribution**, and their interaction. Include matched resource capacity, realized use, task family hold-outs, independent evaluator, repeat runs, calibration, confidence/abstention, severe errors, time and SOP development cost. Test decision-set insufficiency, out-of-distribution changes, stale state, option order, multistep updates and fallbacks. A result on Jev 1.13 cannot be silently applied to Jev 1.14.

Potential program routing:
- SCF: effect of a learned decision layer on system properties
- ASR: policy of selecting Jev, LLM, code or human contingent on information and uncertainty
- SDR: long-horizon error propagation, state staleness, detection and recovery
- CSCI / X2: effects moderated by model cognitive capability or domain/risk boundaries

No result is claimed: all of these are **proposed tests**, not executed experiments.

## 5. Candidate interpretation and decision still OPEN

`System Intelligence` remains a **high-level construct**, operationalized by conditional capability frontiers, task variation/generalization, robustness, adaptability, efficiency, viability and calibrated decision-process measures. Do **not** introduce a sixth universal score/primitive merely because specialized decision models are popular.

Candidate mother-question refinement: *How do generative reasoning, learned bounded judgment, procedural skills, knowledge, system-level control, execution and feedback interact under explicit boundaries to determine attainable capability and its transfer?* Generative LLM remains the current focal subject; its causal necessity is a hypothesis, not an axiom.

**Human decision requested for next round:** if a Jev-style decision core plus non-LLM SOP passes pre-registered G2/G3 generalization and reliability gates without any generative LLM, should it qualify as an SIS **core scientific stress case** (while keeping LLM-centered systems as the main applied study)? Recommended **YES**; this does not mean admitting all conventional ML research to SIS.
