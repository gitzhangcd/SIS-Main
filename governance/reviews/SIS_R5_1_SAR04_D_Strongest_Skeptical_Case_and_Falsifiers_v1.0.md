## S2 · F0–F3 are neither ordinal intelligence nor necessarily exclusive

Persistent SOP text can be a durable asset and simultaneously encode a changed decision policy (F1+F2). A multi-asset accepted update may install a skill and modify its future updater (F1+F3). A human-authored optimizer can count as a changed installed operator but not endogenous self-modification. Thus a **single `max(F)`** silently discards central scientific distinctions.

**Falsifier:** a factorial multi-asset/actor design which separately measures persistence, decision semantics, installed use, author, proposal and approval. ## S3 · Better target ≠ better improver ≠ stronger future improvement

Target performance can improve under an unchanged `I_g`. An installed `I_(g+1)` can reduce **future** performance, especially after overfitting an evolve/promotion set. Changing E*, using more compute, swapping stronger pretrained components or censoring failed/rolled-back attempts can fake improvement. The constructed 24-pair +0.250 numerical toy **demonstrates an analysis pipeline**, not a measured population/meta effect.

**Falsifier:** preregistered paired or randomized old/new effective I on identical frozen `T_g`, independent untouched `D_future`, protected immutable external `E*`, balanced access/resources, measured actual costs and all attempts, prespecified clustered/opportunity-level inference and adverse outcomes. ## S4 · One version contrast does not establish recursive meta-improvement

A successful one-shot `I_g→I_(g+1)` with a positive effect fails to show that later I versions can autonomously improve the *improver of improvers*. True recursive claims need version/authority/causal inheritance over multiple generations, and separation of changes in the future updater from changes to the improvee.

**Falsifier:** independently preregistered multigeneration test with per-generation I hashes, semantically meaningful operator modifications, actor/permission receipts, future-opportunity sampling and proper evaluation boundaries. One or a finite positive sequence is still not proof of *unbounded* recursion.
