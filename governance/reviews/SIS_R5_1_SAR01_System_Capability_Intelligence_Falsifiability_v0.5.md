# SAR-01 Round 7 — Capability, System Intelligence, LLM Contribution & Falsifiability

> **OPEN / NON-NORMATIVE SCIENTIFIC REVIEW — NOT FROZEN.** No change to R5.1 Master or Core schema. User favors Scheme A: an advanced, non-LLM procedural body may independently perform tasks, and that is a valid system-capability finding. LLM necessity, incremental contribution and generalizable system-intelligence claims must be separated.

## Candidate scientific interpretation

**Three non-equivalent questions:**
1. **System Capability**: What does the system achieve on the declared task distribution and information/resource/risk envelope? Align with R5.1's Capability Frontier, Efficiency, Viability, Robustness and Adaptability.
2. **System Intelligence (higher-level construct, NOT a new Core primitive)**: How flexibly and reliably can the system apply/recombine capabilities under relevant task and environmental variation, limited priors, uncertainty and feedback? Do not collapse the five R5.1 properties into a universal score.
3. **LLM Causal Contribution**: What incremental change does the LLM cause relative to a scientifically fair non-LLM policy/controller using the same body/manual, and how does this effect depend on cognitive capability?

**Conceptual asymmetry:** A fixed procedure may generalize across unseen combinations, so fixed ≠ unintelligent. An adaptive agent may fail, so adaptation ≠ adaptability. Excellent G0 task performance does not independently establish G2–G4 generalization. A no-LLM B3 control may match or exceed the LLM system; that is valid negative/zero-effect evidence for LLM necessity, not a reason to discard the task capability observation.

## Primary science boundary resolution — proposal only

SIS's **target domain** in the current user-selected formulation is LLM/LMM-centered systems and mechanisms of external compensation, information, procedure, control and feedback. Non-LLM-only pipelines can serve as comparable **system-science controls and empirical mechanism evidence** without automatically making all conventional automation an independent primary SIS research program. LLM as *focal experimental cognitive component* is not the same as LLM as a *necessary causal component in every task*.

This aligns with the current R5.1 text: §§1–4 (scientific identity, no architectural superiority premise, system capability ≠ model capability), §§13–20 (five properties and trajectory), §§22–38 (SCF/SDR/ASR, CSCI/X2), §§65–68 (evidence independence), §§74–82 (claim maturity). Part VII-A is separately **PROPOSED**, not adopted.

## Candidate mother question (NOT adopted)

In LLM/LMM-centered systems with declared task, information, resource and risk conditions, how do core-model cognitive-interface competence, non-LLM external procedures and execution tools, structured knowledge, organization, state and feedback jointly determine attainable system capabilities, flexible goal achievement across task variation, robustness and viability? When is the LLM necessary, redundant or harmful, and under what task/cost/risk boundaries can external support compensate for weak-model limitations or feedback shift these frontiers?

**No new Primary Program implied.** SCF studies capability formation, SDR time-dependent change, ASR information-conditioned policy selection, and CSCI/X2 capability interactions/boundaries.

## Proposed experiments and non-regression tests — not run

| Test | Required comparison / failure condition |
|---|---|
| SOP-complete task | LLM+B3 vs fair non-LLM rule-router+B3; equal performance limits LLM-necessity claims |
| General-purpose fixed algorithm | G2 novel task recombinations; do not pre-classify fixed as lacking generalization |
| Harmful LLM | negative LLM treatment effect is valid mechanism/boundary evidence |
| Manual/evaluator leakage | prewritten test answers and hidden grade rules disqualify generalization claims |
| Feedback memorization | feedback-trained vs equal-budget generic-trained model, evaluated with frozen body on unseen tasks/tools |
| Unjustified equivalence | no significant difference is not non-inferiority; margin and confidence bound must be pre-registered |
| Scope expansion | fully non-LLM machine-learning research does not automatically become an independent SIS target |

Claims of intelligence *generalization* need task variation, traceable priors/costs and boundary-qualified outcomes. Mere feasibility/performance descriptions remain legitimate CL0–CL1 evidence and are not mislabeled causal discoveries.
