## A. Scientific Identity｜候选 v0.8

> **System Intelligence Science（SIS）研究在明确任务、环境、信息、资源、时间和风险边界下，能力承载系统中的组件能力、程序化知识、组织关系、状态、观察、控制和反馈机制，如何形成、维持、改变及调节系统级能力、效率、可行性、鲁棒性和适应能力，以及这些关系在何种条件下具有因果性、可推广性和可迁移性。**
>
> **SIS 的科学身份由所研究的系统级性质、科学问题与可检验的机制、动态或调节关系确定，而不是由 LLM、Jev、Agent、学习算法、组件数量或实现架构确定。** 生成式大模型、专用决策模型和固定程序可以作为不同能力组件；普通算法与组件性能结果可以提供有用证据，但不自动构成独立的 SIS 系统机制发现。

`System Intelligence` 仍是高层、多维解释性构念；**not a new Core primitive and not a universal scalar**. The five separately measurable R5.1 system properties remain Capability, Efficiency, Viability, Robustness, Adaptability.

## B. First-Principles Mother Problem｜候选 v0.8

> **在给定任务分布与信息、资源、时间及风险约束下，系统内部与外部的能力资源、知识、组织、状态、观察、反馈和控制，如何共同决定可实现的系统级能力前沿及其他性质？不同组件或机制何时必要、冗余、互补、相互抵消或引入风险；这些作用如何随时间和任务条件改变，能否通过有效测量、因果识别、独立验证与边界检验形成可累积的科学知识？**

No assumption that a strong body necessarily replaces a stronger brain; no assumption of positive LLM contribution or that feedback/repeated task improvement constitutes RSI.

## C. Scientific Scope Gate｜S1–S5 (review proposal, NOT a new Core schema)

| Check | Minimal scientific question | Constraint |
|---|---|---|
| **S1 System referent / context** | What system, task distribution, information, resource, time and risk conditions? | LLM, Jev, fixed rule, number of components and brand not admission criteria |
| **S2 System property** | Which conditional Capability, Efficiency, Viability, Robustness, Adaptability or operationalized higher-order construct? | Isolated component score is not automatically system intelligence |
| **S3 Scientific question / estimand** | Description versus mechanism/organization, time-dependent trajectory or evidence-conditioned regulation? | CL0/CL1 valid; explanatory claims require testable/defeasible question and competing explanation; abstain if no estimand |
| **S4 Sources of competence & roles** | Who authored SOP/options? Which knowledge, state, human permission, tool execution and independent evaluator actually contributed, and when? | Precompiled expert capability is not automatically LLM reasoning |
| **S5 Evidence ceiling / boundary** | What can the current design actually support, including null/negative effects, uncertainty and untested boundary? | Performance ≠ causality; package noninferiority ≠ cognitive equivalence; repeated optimization ≠ RSI |

S1–S5 are **review controls, not five new ontology dimensions**. Do not replace `ROUTED`, `DESCRIPTIVE_ONLY`, `ROUTING_UNRESOLVED`, `SCIENTIFIC_NONCONFORMANT`; five SAR-01-B scope triage labels remain review-only.

## D. Strongest two surviving skeptical objections (OPEN)

**O1 — Over-inclusion.** Nearly every program can be represented as having components, state and control. Even a Scope Gate can amount to subjective labeling unless independent reviewers can consistently distinguish routine software engineering from a meaningful system-level scientific question. **Falsifier/rework trigger:** ordinary scripts, symbolic algorithms and fixed SOPs are indiscriminately promoted to core SIS explanatory discoveries merely by renaming them.

**O2 — Under-inclusion.** Requiring causal identification *before* admission would exclude valid descriptive/measurement research, deterministic planners, formal guarantees and potentially generalizable fixed systems. **Falsifier/rework trigger:** studies with a precise system-level referent and CL0/CL1 evidence are marked entirely outside scope because no CL2 effect has yet been established.

These are the **only two irreducible open objections** for this minimal synthesis; detailed RSI precision is deferred to SAR-04 without adding a new primary program.

## E. A/B stress cases preserved

- **A fixed SOP:** bounded capability and no-LLM negative-control evidence are valid. A controlled verifier effect may be SCF; time-dependent error propagation may be SDR; an information-conditioned retry/escalation policy-value question may be ASR. Fixed ≠ automatically unintelligent; successful automation ≠ universal intelligence discovery.
- **B Jev-like bounded decision + SOP:** in scope **without** a generative LLM when the system-level scientific question is explicit. Candidate-option generation, learned selection, state freshness and execution authority remain distinct. Typed output ≠ semantic correctness/safety.
- **C weak LLM + strong non-LLM body/manual:** local system noninferiority and unique causal body/LLM contribution are **different claims**; no-brain control, information/resource matching and noninferiority margin are required for respective stronger claims.
- **D feedback / self-improvement:** SCF/SDR/ASR cover abstract mechanism, trajectory and adaptive choice; exact meta-improver revisions and independent future improvement evaluation remain OPEN for SAR-04. Repeated better scores ≠ identified recursive self-improvement.
