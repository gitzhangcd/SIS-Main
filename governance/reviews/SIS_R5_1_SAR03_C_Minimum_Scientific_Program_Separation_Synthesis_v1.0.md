## 2. Minimal separation contract

**SCF** if the primary question concerns how specified mechanism / organization / component interaction changes a **system-level property**, with appropriate contrast and scientific evidence. Fixed SOP verifier versus no verifier remains SCF by its estimand, even if an agent calls the tool. It is not ASR simply because a policy is present.

**SDR** if the **target estimand** is a functional of state transitions/trajectory/failure propagation/containment/recovery/long horizon. The same endpoint can mask different recovery duration or propagation paths; a timestamp is not sufficient.

**ASR** if the target is the **information-conditioned endogenous action selection or policy value** under legally available `H_t`; `NO_CHANGE`, `ABSTAIN` and `STOP` are valid actions. A policy may cause a trajectory but policy-value and trajectory-effect estimands are not automatically the same claim.

**Routing rule:** Identify a single PrimaryEstimand before applying conditional precedence `DecisionSelection > Trajectory > StaticMechanismEffect`. If unclear, `ROUTING_UNRESOLVED`; do **not** use the precedence as a keyword-based rescue rule. Separate SCF/SDR/ASR claims from one experiment per source §44.

**Cross-cutting:** CSCI and X2 never become substitute Primary Programs; model IDs and nominal domains are insufficient to infer their scientific constructs.

## 4. M1/M2 scientific comparability

M1 is a **known/bounded component universe `C*` with time-dependent activation**; M2 is an **unadopted open-identity membership candidate `C_t`**. For a *claimed common estimand*, evaluate:
1. real component boundaries, identity/creator/generation/version/lifecycle;
2. effective organization `R_t`, permission and actual execution receipts;
3. legal decision-time information and evaluator separation;
4. task distribution, resources, budget, risk and time horizon;
5. **intervention correspondence and PrimaryEstimand preservation**.

In SAR-03-B's bounded counterexample, `Y_A=I×P` and `Y_B=I` match at `I=P=1` but differ for `do(P=0)`. Equal observed outcomes do not imply the same component-level causal effect. Final label equality also does not distinguish delete/recreate from disable/enable; event identity is needed.

**Disposition is claim-dependent:**
- only performance comparison → `DESCRIPTIVE_ONLY` may remain valid;
- common estimand unrecoverable because mapping absent → `ROUTING_UNRESOLVED`;
- causally identified equivalence asserted despite differing interventions / leakage / hidden strong model → `SCIENTIFIC_NONCONFORMANT`;
- conditional comparability requires explicit mapping; otherwise annotate `REGIME_COMPARABILITY_UNRESOLVED` as **review-only**, not a fifth canonical status.
