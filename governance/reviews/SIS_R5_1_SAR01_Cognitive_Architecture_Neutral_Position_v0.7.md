# SAR-01 v0.7 | Cognitive-Architecture-Neutral System Intelligence

> **REVIEW POSITION CONFIRMED BY USER, SAR-01 STILL OPEN / NOT FROZEN.** This file records the science-owner's discussion answer on 2026-10-28. It is not a new normative master version, proof of a scientific law, or approval for merging into the canonical specification.

## User scientific position

The user answered **YES** to this boundary question:

> If a system uses no generative LLM, but a Jev-like learned bounded decision model, a strong non-LLM execution body and structured knowledge, and reliably solves complex *previously unseen combinations of tasks* (rather than a precompiled answer), should SIS study it directly?

**Answer: YES.**

Interpretation: The SIS scientific object cannot require a generative LLM as a necessary component. LLM/LMM-centered systems remain a key initial empirical emphasis, not an ontological admission criterion. Component architecture, marketing type, number of components and choice/output format are not sufficient to decide a scientific claim's validity.

## Scientific identity candidate v0.7 (PROPOSED)

**System Intelligence Science (SIS)** studies how cognitive/decision capabilities, non-model execution resources, structured scientific knowledge, procedural skills, system organization, explicit state, information acquisition, regulation, and feedback jointly form, constrain, maintain, and change a system's **task- and context-conditional capabilities and system-level properties**. It asks when weak components can be compensated by external systems; when a learned cognitive component is necessary, redundant or harmful; and whether feedback shifts the capability frontier on independent tasks and environments. The implementation may include generative LLMs/LMMs, specialized learned decision models, rule-based controllers, tools or combinations thereof, with their roles explicitly specified.

This is **not** a statement that all traditional machine-learning research or all software engineering belongs to SIS. Distinct:
- **Scientific scope:** explicit system boundary, task/context and target system property; system-level explanatory/scientific question, not merely a model or framework name.
- **Scientific contribution:** meaningful system mechanism, capability boundary, generalization or dynamic/regulatory finding.
- **Claim strength:** depends on construct measurement, causal identification, evidence independence, resource/information controls and tested boundaries. Descriptive/CL0–1 evidence is legitimate and not automatically promoted.

## Ontology and program economy

No automatic new primitive or program follows. Existing SIS `Components + Relations + State + Observation + Control + Dynamics`, Capability Frontier and `SCF / SDR / ASR` plus cross-cutting `CSCI / X2` can in principle represent both generative and decision-model architectures. This **expressibility** needs adversarial and empirical confirmation; it is not yet an executed non-regression pass.

A fixed-SOP-only system can provide **system-capability data, boundary cases and no-LLM controls**. Jev-like learned decision model + SOP + manual with demonstrated G2/G3 generalization can be an **independent primary system-intelligence study**, not only a control. Any claim of generalizable intelligence requires measured task variation and capabilities, not the mere presence of an AI-labelled component.

## Three claim layers

1. **System capability:** attainable outcomes under stated task distribution, resource, information and risk context, even if largely precompiled.
2. **System intelligence (higher-level construct, not Core primitive):** evidence for flexible capability across measured task and environmental changes; maintain separate reliability, adaptability, viability and costs; do not invent a universal intelligence scalar.
3. **Cognitive-component contribution:** conditional causal effect of learned/bounded decision components or generative LLMs compared with fair no-model and fixed-controller baselines; null or negative value is an allowed outcome.

## Falsifiable study contrasts (NOT EXECUTED)

- Fixed-rule controller + same B3 SOP + knowledge.
- Jev-like learned bounded decision model + identical B3 SOP + knowledge, no generative LLM.
- Weak generative LLM + identical B3 SOP + knowledge.
- Weak LLM + bounded decision model + identical B3 SOP + knowledge.
- Stronger LLM + minimal tools/manual (candidate compensation reference).

Pre-register G0–G4 generalization and error/safety/cost gates; verify authority, state freshness, option-set adequacy, hidden stronger-model absence, answer leakage, SOP creation effort, task-family splits and evaluator independence.
