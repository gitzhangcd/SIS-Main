## Main scientific signals

1. **Fault regime changes causal leverage.** Model behavior can dominate under observable outcomes while contract semantics dominate when ambiguity/fault conditions change.
2. **Trace availability is not trace integrity.** If the acting system can rewrite/delete its own trace, post-hoc diagnosis loses evidence independence.
3. **Decision authority should be separable from agent claims.** Specification/evidence-controlled state is scientifically distinct from an agent saying a task is complete.
4. **Component × system interactions remain first-class.** The return to reusable skills varies substantially across model configurations.
5. **Selective regulation is a stronger target than unconditional optimization.** Deviation-localized repair, multi-fidelity evaluation, and explicit hypothesis testing all motivate action-selection/value-of-information experiments.
